TDL - Twitch Dragonborn Legacy 1.2.1
====================================

Зрители вашего Twitch управляют Skyrim: награды за баллы канала, биты, команды
чата и голосования вызывают драконов, охотников, проклятия, телепорты, погоду и
многое другое. С версии 1.1 мод сам подключается к Twitch - без Streamer.bot и
сторонних программ.

Полная документация: Data\TDL\Documentation (английский + русский).
Поддержать автора: https://boosty.to/skeorz
Новое в 1.2: оверлей для OBS, ответы в чат, пауза, анти-спам, статистика зрителей, рейды/сабы/hype train,
голосования в чате, звуковой сигнал - см. Documentation\9_twitch_dragonborn_legacy_stream_features.md


Требования
----------
- Skyrim Special Edition / Anniversary Edition (проверено на 1.7.104)
- SKSE64 под вашу версию игры
- Address Library for SKSE Plugins
- powerofthree's Papyrus Extender
- ConsoleUtilSSE NG (версия с поддержкой вашей версии игры)
- SkyUI + MCM Helper (меню настроек в игре)
- UIExtensions (радиальное меню и меню статистики)
Мультиязычность «из коробки»: мод сам переключается на язык игры (9 языков), отдельные переводы не нужны.
Необязательно: True Directional Movement, TrueHUD, Target Focus (нужны некоторым стадиям).


Быстрый старт
-------------
1) Установите архив через менеджер модов (Vortex / MO2) и включите его.
   Не ставьте TDL_RespawningEncounterZones.esp и Tdl_patch1.esp из старых версий:
   модуль респауна теперь встроен (MCM -> страница «Телепорт»).
2) Запустите игру через SKSE.
3) Только при первом запуске: игра покажет код и откроет в браузере
   twitch.tv/activate. Войдите в аккаунт, С КОТОРОГО СТРИМИТЕ, и введите код.
   Вход хранится в зашифрованном виде для вашего пользователя Windows:
   Документы\My Games\Skyrim Special Edition\SKSE\TDL_Twitch.token
   (удалите этот файл, чтобы выйти).
4) Загрузите сохранение и напишите в чат своего канала:  !tdl_heal
   Вас вылечит, а в левом верхнем углу появится «<ваш ник> исцелил вас».


Что доступно зрителям
---------------------
Всё настраивается в  Data\SKSE\Plugins\TDL_Twitch.ini  (UTF-8, изменения
применяются прямо во время игры):

[Rewards]   название награды за баллы = действие(я)   (только компаньоны/партнёры)
[Bits]      минимальная сумма = действие(я)           (срабатывает наибольший порог)
[Chat]      !команда = действие(я)                    (по умолчанию стример/модераторы)
[Poll]      победивший вариант голосования = действие(я)
[Messages]  действие = текст в игре, {user} = ник зрителя, {trigger} = чем запустил

Значение может быть:
  ACTION                одно действие, например SUMMON_DRAGON
  A, B, C               случайное из списка (уровни сложности)
  FORCE|ACTION|COUNT    серия (см. ниже)

В файле по умолчанию - четыре уровня сложности (лёгкий / средний / тяжёлый /
эпический) для наград и битов, несколько команд чата и игровые сообщения на
русском. Создайте награды в панели Twitch с названиями точно как в [Rewards]
(или поменяйте названия в INI).

Параметры [Twitch]:
  Enabled=1             0 = не подключаться к Twitch
  ChatAllowEveryone=0   1 = команды чата от всех, а не только от стримера/модераторов
  Notify=1              сообщения в игре «кто что сделал»
  PollName=Чат          от чьего имени объявляются итоги голосования

--------

             SUMMON_UNDEAD  SUMMON_STRONG  SUMMON_DRAGON

Хаос:        CHAOS_LOW_G  CHAOS_BACKFIRE
Инвентарь:   INVENTORY_SCATTER  INVENTORY_DROP_ALL
Телепорт:    TELEPORT_RANDOM_CITY  TELEPORT_RANDOM_DANGER  TELEPORT_HIGH_HROTHGAR
             TELEPORT_WHITERUN  TELEPORT_SOLITUDE  TELEPORT_WINDHELM  TELEPORT_RIFTEN

дважды, прежде чем отдавать их чату.


Очередь и кулдауны
------------------
Каждое действие относится к группе (призыв, погода, телепорт...). Группа
выполняет одно действие и ждёт кулдаун, остальные стоят в очереди (до 15 на
группу, 8 для вируса/шоу/инвентаря). Приоритет: биты > баллы и чат > голосования.
Кулдауны: Data\TDL\config\TDL_Cooldowns.ini (читается при запуске игры).


FORCE (серии, для стримера)
---------------------------
FORCE|ACTION|COUNT[|INTERVAL] - серия без учёта кулдаунов. Разрешено:
SUMMON_* (до 50), INVENTORY_SCATTER (10), TELEPORT_RANDOM_CITY (5),
TELEPORT_RANDOM_DANGER (5), VIRUS_DISEASE (15). Интервал 0,75-5 с (телепорты 7-10 с).
FORCE1|ACTION - одно действие сразу: SYSTEM_HEALING, WRATH_11/12/13.
Тяжёлые серии могут подвесить или уронить игру - используйте осознанно.


Управление без Twitch (для продвинутых)
---------------------------------------
Плагин также принимает строки через именованный канал \\.\pipe\TDL_Stream, например:
  SYSTEM_PING|2     FORCE|SUMMON_SKELETON|3     FORCE1|SYSTEM_HEALING
Скрипты send_raw.cmd / send_raw.ps1 (PowerShell) для этого лежат в репозитории на GitHub
(Data/TDL/tools); для игры они не нужны.
SOURCE: 1 = биты, 2 = баллы/чат, 3 = голосование.


Журналы и проблемы
------------------
Документы\My Games\Skyrim Special Edition\SKSE\TDL_StreamPlugin.log - вход в
Twitch, полученные события («Twitch: !tdl_heal by ... -> SYSTEM_HEALING|2») и
очередь («Dispatch: ...»).

- Нет окна входа / «integration stopped»: перезапустите игру, чтобы получить новый код.
- Команда в чате ничего не делает: по умолчанию команды чата доступны только
  стримеру и модераторам (ChatAllowEveryone=1 это меняет). Смотрите журнал.
- «failed to open address library file»: Address Library не подходит к версии игры.
