TDL - Twitch Dragonborn Legacy 1.3.1-beta
=========================================

Vos spectateurs Twitch contrôlent Skyrim : récompenses de points de chaîne, bits, commandes de chat
et sondages déclenchent dragons, chasseurs, malédictions, téléportations, météo et bien plus encore.
Depuis la version 1.1, le mod se connecte à Twitch de manière autonome — pas besoin de Streamer.bot ni de programme supplémentaire.

Documentation complète : Data\TDL\Documentation (anglais + russe).
Soutenir l'auteur : https://boosty.to/skeorz
Nouveau en 1.3 (bêta) : page de réglages dans le navigateur (MCM -> About), Arène 2.0 - salle dédiée, gong, coffre de récompense
Nouveau en 1.2 : overlay OBS, réponses dans le chat, pause, anti-spam, statistiques, raids/abonnements/hype train,
votes dans le chat, signal sonore - voir Documentation\9_twitch_dragonborn_legacy_stream_features.md


Prérequis
---------
- Skyrim Special Edition / Anniversary Edition (testé sur 1.7.104)
- SKSE64 pour votre version du jeu
- Address Library for SKSE Plugins
- powerofthree's Papyrus Extender
- ConsoleUtilSSE NG (une version compatible avec votre version du jeu)
- SkyUI + MCM Helper (menu des paramètres en jeu)
- UIExtensions (menu radial et menu des statistiques)
Multilingue d'origine : le mod suit la langue du jeu (9 langues), aucun fichier de traduction n'est nécessaire.
Optionnel : True Directional Movement, TrueHUD, Target Focus (utilisés par certaines étapes).


Démarrage rapide
----------------
1) Installez l'archive avec votre gestionnaire de mods (Vortex / MO2) et activez-la.
   N'utilisez pas TDL_RespawningEncounterZones.esp ni Tdl_patch1.esp des versions
   précédentes — le module de respawn est désormais intégré (MCM -> page Teleport).
2) Lancez le jeu via SKSE.
3) Premier lancement uniquement : le jeu affiche un code et ouvre twitch.tv/activate dans votre
   navigateur. Connectez-vous avec le compte depuis lequel vous diffusez en STREAM et saisissez le code.
   La connexion est stockée sous forme chiffrée pour votre utilisateur Windows dans
   Documents\My Games\Skyrim Special Edition\SKSE\TDL_Twitch.token
   (supprimez ce fichier pour vous déconnecter).
4) Chargez une sauvegarde et écrivez dans votre chat Twitch :  !tdl_heal
   Vous recevez des soins et voyez "<votre nom> исцелил вас" dans le coin supérieur gauche.


Ce que les spectateurs peuvent utiliser
---------------------------------------
Tout se configure dans  Data\SKSE\Plugins\TDL_Twitch.ini  (UTF-8, les modifications
s'appliquent pendant que le jeu est en cours d'exécution) :

[Rewards]   titre récompense points de chaîne = action(s)   (Affiliés/Partenaires uniquement)
[Bits]      montant minimum = action(s)                     (le seuil le plus élevé l'emporte)
[Chat]      !commande = action(s)                           (diffuseur/modérateurs par défaut)
[Poll]      titre du choix gagnant = action(s)
[Messages]  action = texte en jeu, {user} = nom du spectateur, {trigger} = ce qui a été utilisé

Une valeur peut être :
  ACTION                une seule action, ex. SUMMON_DRAGON
  A, B, C               une action aléatoire dans la liste (paliers de difficulté)
  FORCE|ACTION|COUNT    une rafale (voir ci-dessous)

Le fichier par défaut propose quatre paliers de difficulté (léger / moyen / lourd / épique) pour
les récompenses et les bits, quelques commandes de chat et des messages en jeu en russe — traduisez
[Messages] dans votre langue si vous le souhaitez. Créez les récompenses dans votre tableau
de bord Twitch avec exactement les titres de [Rewards] (ou renommez-les dans le fichier INI).

Options de [Twitch] :
  Enabled=1             0 = pas de connexion Twitch
  ChatAllowEveryone=0   1 = commandes de chat pour tous, pas seulement diffuseur/modérateurs
  Notify=1              messages en jeu du type "qui a fait quoi"
  PollName=Чат          nom utilisé dans les messages pour les résultats de sondage

File d'attente et temps de recharge
-----------------------------------
Chaque action appartient à un groupe (invocation, météo, téléportation...). Un groupe déclenche
une action à la fois, puis attend son temps de recharge ; les autres attendent dans la file d'attente
(jusqu'à 15 par groupe, 8 pour virus/spectacle/inventaire). Priorité : bits > points de chaîne
et chat > sondages. Temps de recharge : Data\TDL\config\TDL_Cooldowns.ini (lu au lancement du jeu).


FORCE (rafales, pour le streameur)
----------------------------------
FORCE|ACTION|COUNT[|INTERVAL] déclenche une série et ignore les temps de recharge. Sont autorisés :
SUMMON_* (jusqu'à 50), INVENTORY_SCATTER (10), TELEPORT_RANDOM_CITY (5),
TELEPORT_RANDOM_DANGER (5), VIRUS_DISEASE (15). Intervalle de 0.75-5 s (téléportations 7-10 s).
FORCE1|ACTION déclenche une action immédiatement : SYSTEM_HEALING, WRATH_11/12/13.
Les rafales lourdes peuvent figer ou faire planter le jeu — utilisez-les avec discernement.


Contrôle local sans Twitch (avancé)
-----------------------------------
Le plugin écoute également sur le canal nommé (named pipe) \\.\pipe\TDL_Stream pour des lignes comme
  SYSTEM_PING|2     FORCE|SUMMON_SKELETON|3     FORCE1|SYSTEM_HEALING
Les scripts send_raw.cmd / send_raw.ps1 (PowerShell) se trouvent dans le dépôt GitHub
(Data/TDL/tools) ; ils ne sont pas nécessaires pour jouer.
SOURCE: 1 = bits, 2 = points/chat, 3 = poll.


Journaux et dépannage
---------------------
Documents\My Games\Skyrim Special Edition\SKSE\TDL_StreamPlugin.log indique la connexion
à Twitch, les événements reçus ("Twitch: !tdl_heal by ... -> SYSTEM_HEALING|2")
et la file d'attente ("Dispatch: ...").

- Pas de fenêtre de connexion / "integration stopped" : redémarrez le jeu pour obtenir un nouveau code.
- Une commande de chat ne fait rien : par défaut, seuls le diffuseur et les modérateurs peuvent
  utiliser les commandes de chat (ChatAllowEveryone=1 modifie cela). Vérifiez le journal.
- "failed to open address library file" : Address Library ne correspond pas à votre version du jeu.
